Install the nereus CLI

On Linux (x86_64, aarch64):

curl -fsSL https://getnereus.github.io/install/install.sh | sh

It downloads the wheel of the latest release, checks its sha256, installs uv when it is missing and runs uv tool install. A pinned version: NEREUS_VERSION=0.1.23; every option: sh -s -- --help.

The CLI upgrades itself in the background; turn it off with NEREUS_AUTO_UPGRADE=off or nereus config set auto_upgrade off.
